# Лабораторная работа № 3

В работе реализованы линейная регрессия и логистическая регрессия на NumPy. Для обучения используется пакетный градиентный спуск. Результаты сравниваются с моделями из scikit-learn.

В папке лежат исходные данные, код моделей и отчёт с полученными метриками. Файл `TASK.md` содержит исходное описание задания.

Чтобы пересчитать результаты, установите библиотеки и запустите скрипт:

```bash
python -m pip install -r requirements.txt
python run_experiments.py
```

В эксперименте использовано разбиение 80/20 с `random_state=42`. MSE линейной регрессии на тестовой части равна 4.08. Собственная логистическая регрессия получила ROC-AUC 0.808 и accuracy 0.77.

Подробные результаты и выводы находятся в [REPORT.md](REPORT.md), численные значения также сохранены в [experiment_results.json](experiment_results.json).
